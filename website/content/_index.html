Proving Photos Are Real in the Age of AI

Take a picture. A fingerprint of the file is recorded in a public registry run by journalism organizations. Anyone holding that file can check that it came from a registered camera, and no one can use the registry to find out which camera took it.

The Argument

1. Looking Real No Longer Proves Anything

AI can now produce images that pass as photographs, and any inconvenient photograph can be dismissed as fake. The useful question is no longer "does this look real?" but "where did this come from?" Only the capture hardware can answer that.

2. Proof Inside the File Gets Stripped

Embedded credentials such as C2PA Content Credentials live inside the file. Social media platforms routinely strip that data through compression and format conversion, so the proof is often gone by the time an image reaches its audience. The record has to live outside the file.

3. A Record of Cameras Is a Map of Photographers

A registry that links cameras to images is also a map of who photographed what. For journalists, activists and their sources, a breach of that map is exactly the harm a provenance system must not cause. So the map must never be built.

What Birthmark Does

When a registered camera saves a photo, it sends a fingerprint of the file (a SHA-256 hash) and its encrypted credential as two separate messages, along separate paths, to separate servers. The manufacturer confirms the camera is registered without ever seeing the fingerprint. Independent servers confirm the two messages belong together. Only then is the fingerprint recorded in the Birthmark Media Registry.

The registry record holds no camera, manufacturer or photographer identifier. The information that would link a camera to a picture never comes together in one place, so a breach of any single server exposes a fragment, not a map. This is a property of the architecture, not a promise of good behavior, and it is backed by machine-checked proofs for each component.

The registry is a blockchain operated by a consortium of journalism, fact-checking and press freedom organizations, not by a technology company. There is no cryptocurrency and no transaction fee.

What It Proves, and What It Doesn't

✅ It Proves

That a file came from a registered capture device, how it was processed, and roughly when it was registered. Edits made in certified editing software stay linked to the original.

❌ It Doesn't Prove

That the scene is true. A staged scene passes, as does a photo of a screen or print. Judging what an image shows still takes journalistic judgment.

⚠️ It Needs an Exact Copy

Matching is exact. A file changed outside certified software, including by a platform's recompression, has no record. A missing record proves nothing on its own.

Where We Are

An early prototype on Raspberry Pi 4 hardware demonstrated the full pipeline, from sensor capture to registry lookup, for an earlier version of the design. The protocol has since been redesigned so that no single component can link a device to its content. Its privacy properties are checked with machine-verified proofs, and its resistance to timing analysis has been evaluated in simulation. Next comes a reference implementation of the current design, measured on real camera-class hardware, and a pilot with journalists and photographers.
