Bringing back “pics or it didn’t happen”

Proving Photos Are Real in the Age of AI

Take a picture. A fingerprint of the file is recorded in a public registry run by journalism organizations. Anyone holding that file can check that it came from a registered camera, and no one can use the registry to find out which camera took it.

How it works

A registered camera computes a fingerprint of each photo. The registry records the fingerprint, a verdict on how the image was processed, and a coarsened time. The registry never receives the photo, and no single system sees both who took it and what it shows. Anyone with the file can check it.

See how it works →

The fingerprint

Change one pixel and the whole fingerprint changes. A record matches only an exact copy of a file.

What a record proves

  • The file came from a registered capture device.
  • How the image was processed after capture.
  • Roughly when it was registered.

What a record does not prove

  • That the scene is true. Staged scenes and photos of screens pass.
  • Anything about a photo from a manufacturer that does not participate. A missing record is not evidence of fakery.

Status

The protocol is specified, formally modeled and simulated. Twelve security properties are machine-checked across eleven ProVerif models. An earlier design ran on a Raspberry Pi 4 prototype.

Next: a reference implementation on camera-class hardware, then a pilot with journalists and photographers. Journalism and press-freedom organizations will operate the registry once it launches.
