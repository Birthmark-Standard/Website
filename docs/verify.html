Understanding Verification Results

A matching record shows that the file came from a registered capture device. Each record carries a one-byte Modification Verdict describing how the image was processed.

Unedited Capture

Verdict of Zero

The image as saved by a registered camera or capture app, with no edits declared. A RAW file and a processed JPEG from the same capture are registered as separate records.

Guarantee: This exact file came from a registered capture device.

Edited

Tool-Class Flags

Edited in certified editing software. The verdict records which classes of tool were used: tone and colour, detail, geometry, content removal or alteration (including generative tools), and compositing. It also gives one of four levels of deviation from what the declared edits predict.

Guarantee: Linked to a registered original; the classes of edit are declared by the software and judged by its developer.

Undeclared Change

Flagged Record

The saved image differs from what the declared edits predict by more than the developer's threshold, and no content-changing tool was declared. The record is kept, with the flag set.

Guarantee: Linked to a registered original, but the image changed in a way the declared edits don't explain.

Edit Chains

The record for an edited image carries the fingerprint of the image it was made from. You can use that fingerprint to look up the earlier record, step by step, back to the original capture. Tool-class flags accumulate along the chain, so a later edit's verdict includes the classes of tool used in earlier edits.

Example: A news photo that has been cropped and colour-corrected in certified software shows the geometry and tone-and-colour flags, with a link back to the unedited capture's record.

Frequently Asked Questions

What if my image is not found?

A missing record proves nothing on its own. It could be because:

  • The image was captured by a device whose manufacturer doesn't take part
  • The file was changed after it was registered (for example recompressed, resized or stripped of metadata)
  • The image was AI-generated or created digitally
  • The record hasn't been finalized yet; records appear minutes after capture

Why doesn't my edited copy match?

The registry matches files exactly. Any change since registration produces a different hash. Edits made in certified editing software create their own record linked to the original; edits made elsewhere don't.

Can screenshots be verified?

No. A screenshot is a new file with a different hash. If you have the original file, unchanged, its hash will match the record.

What about social media compression?

Platforms that recompress or strip metadata from uploads produce a new file with a different hash, so the shared copy won't match. The original file still verifies. Platforms can preserve the link by processing uploads through certified software.

Does a match prove the photo is true?

No. It shows the file came from a registered capture device, not that the scene is real. A staged scene, or a photo of a screen or print, can still match.
